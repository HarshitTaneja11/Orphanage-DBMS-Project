About the Project

Secure Orphanage Resource Management System (SORMS)

"Technology-driven transparency and efficiency in orphanage management."

A full-stack orphanage management system designed to securely manage child welfare records, donations, resource inventory, and allocation tracking. The system integrates a normalized MySQL database with a Python/Flask backend and a responsive frontend dashboard, ensuring efficient operations, transparency, and accountability through automation, audit logging, and role-based access control.

Core DBMS Features

  • Stored Procedures & Functions
  • Triggers & Views
  • Transactions (Rollback/Commit)
  • Role-Based Access Control
  • Indexing & Audit Logging

Key Features

  • Child record management
  • Donation tracking
  • Resource inventory management
  • Automated resource allocation
  • Live dashboard statistics
  • Transaction logging via triggers
  • Role-based access permissions
  • Search & reporting system
